## Показатели

> ТЗ: «Определите **хотя бы один** показатель, который должен измениться».

Варианты из ТЗ: время выполнения процесса · количество ручных действий · количество ошибок ·
доля пользователей, завершивших сценарий · количество повторных обращений · точность подбора
или рекомендации.

| Показатель | Сейчас (As Is) | Цель (To Be) | Откуда взято «сейчас» | Как измерим после запуска |
|---|---|---|---|---|
| | | | ⬜ замер ⬜ источник ⬜ оценка | |
| | | | ⬜ замер ⬜ источник ⬜ оценка | |

**Главный показатель** (один, который выносим на слайд): ______________

Колонка «откуда взято» обязательна. ТЗ допускает гипотезу на этапе хакатона, но требует
показать, «какой эффект продукт должен создать и как его можно будет проверить после запуска».
Оценочная цифра с пометкой об источнике сильнее, чем круглая цифра без него: на защите
оценивается, различает ли команда факты и допущения.

## Что попадёт в презентацию

пометка об источнике цифры. Метрики пилота — в [06-pilot.md](06-pilot.md), это другой слайд
и другой критерий.
