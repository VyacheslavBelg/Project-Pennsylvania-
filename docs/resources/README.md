# Resources — MAX / «Умный город»

Дата сборки: 2026-09-20.

Эта папка — единая точка входа в официальные источники проекта. Принцип: первоисточник > официальная документация продукта > правовая справочная система > отраслевые статьи.

## Что читать в первую очередь

1. ТЗ «Умный город» уже хранится в корне репозитория; `docs/tz/` содержит его структурированную выжимку — ограничения, критерии и обязательные источники.
2. `01_regulatory/01_PP_RF_40_2026.md` — зачем MAX появился в правилах управления МКД.
3. `01_regulatory/02_Order_Minstroy_856pr_2025.md` — фактическая модель взаимодействия MAX ↔ ГИС ЖКХ ↔ организации.
4. `01_regulatory/03_FZ_156_2025.md` — закон о многофункциональном сервисе обмена информацией.
5. `02_gis_gosuslugi/01_Gosuslugi_Dom_capabilities.md` — что уже умеет официальный продукт и что нельзя выдавать за нашу инновацию.
6. `05_analysis/01_legal_product_model.md` — выводы для архитектуры Домового.
7. `05_analysis/02_claims_audit.md` — какие популярные формулировки нельзя использовать без оговорок.

## Правило для презентации

Для нормативных утверждений используйте номер акта, пункт/статью и дату актуальности. Не пишите «по закону» без ссылки на конкретную норму. Если реальной интеграции нет, помечайте данные как модельные/тестовые — это прямо требует ТЗ.
