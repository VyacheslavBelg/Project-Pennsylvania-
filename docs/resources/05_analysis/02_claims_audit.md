# Аудит популярных утверждений о MAX / ЖКХ

## Подтверждено

- С 01.09.2026 Правила № 416 включают многофункциональный сервис в способы взаимодействия УО с собственниками и пользователями.
- Через сервис может осуществляться запись на прием.
- Приказ № 856/пр предусматривает электронный обмен между жителями и широким кругом организаций ЖКХ.
- Организации должны обеспечить непрерывный доступ к базовым контактным сведениям; для РСО — также к сведениям о перерывах ресурсов.
- Обращения/показания/ответы в рамках порядка проходят с использованием ГИС ЖКХ; MAX работает через интеграцию с ГИС ЖКХ.
- «Госуслуги Дом» уже умеет создавать и отслеживать заявки, показывать УО, официальный домовый чат, рейтинг/аналитику УО и важные события.

## Нельзя писать без дополнительного точного основания

- «Любое сообщение в MAX юридически равно бумажному обращению».
- «Все УК, ТСЖ и РСО обязаны принимать обращения через любой бот в MAX».
- «Отказ принять заявку через произвольного MAX-бота автоматически является лицензионным нарушением».
- «MAX сам фиксирует и контролирует все нормативные сроки».
- «Госуслуги Дом не позволяет УК закрыть заявку без подтверждения собственника».
- «Рейтинг УО рассчитывается только по просрочкам, предписаниям и собираемости» — без официальной методики расчета это гипотеза.
- «Из домовых чатов исключены арендаторы/не-собственники по ЕГРН» — официальная справка говорит о доступе собственников и гостей в ряде сценариев, поэтому нужна точная проверка правил конкретного чата.

## Правильная формулировка для презентации

Не «MAX делает обращение юридически значимым», а:

> Законодательство и порядок Минстроя встраивают многофункциональный сервис в официальный контур взаимодействия ЖКХ; передача обращений и ответов организована через интеграцию с ГИС ЖКХ.
