# Федеральный закон № 59-ФЗ — важная оговорка

59-ФЗ регулирует порядок рассмотрения обращений граждан государственными органами, органами местного самоуправления и должностными лицами.

Для обычного обращения непосредственно в управляющую организацию нельзя автоматически использовать «30 дней по 59-ФЗ» как универсальный срок. Срок зависит от типа обращения и специального регулирования ЖКХ (Правила № 416, № 354 и др.).

Использовать 59-ФЗ только там, где адресат и правоотношение действительно попадают в его сферу.
