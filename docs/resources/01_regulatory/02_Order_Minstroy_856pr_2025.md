# Приказ Минстроя России от 29.12.2025 № 856/пр

**Название:** порядок информационного взаимодействия организаций ЖКХ с собственниками/пользователями помещений с использованием ГИС ЖКХ и многофункционального сервиса обмена информацией.

**Регистрация Минюста:** 05.02.2026 № 85248.

**Официальная публикация:** https://publication.pravo.gov.ru/document/0001202602090015

**Справочная копия:** https://www.consultant.ru/document/cons_doc_LAW_526048/

## Ключевая модель

Участники: собственники/пользователи + РСО + региональные операторы ТКО + лица, управляющие МКД + подрядчики по содержанию/ремонту + фонды капремонта.

Информационное взаимодействие идет электронными сообщениями.

Организации должны обеспечить непрерывный доступ к базовым сведениям, среди которых:
- наименование;
- телефон;
- режим работы;
- e-mail (если есть);
- время и адрес приема;
- телефон диспетчерской/АДС;
- для РСО — сведения о ресурсах и перерывах в поставках;
- для фонда капремонта — сведения о работах.

**Критически важно:** обращения жителей, показания счетчиков и ответы организаций осуществляются **с использованием ГИС ЖКХ** в установленные законодательством сроки. Взаимодействие через сервис осуществляется **посредством интеграции с ГИС ЖКХ**.

## Архитектурный вывод

MAX — пользовательский/транспортный слой. ГИС ЖКХ — официальный системный контур и source of truth для юридически значимых обращений в модели приказа.
