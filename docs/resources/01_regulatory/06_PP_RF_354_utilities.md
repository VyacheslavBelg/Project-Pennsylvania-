# Постановление Правительства РФ от 06.05.2011 № 354

**Название:** правила предоставления коммунальных услуг.

**Актуальная справочная редакция:** https://www.consultant.ru/document/cons_doc_LAW_114247/

## Для сценария «нет воды»

Приложение № 1 задает требования к качеству коммунальных услуг и допустимую продолжительность перерывов.

Пример: для горячего водоснабжения установлены допустимые перерывы, включая отдельное правило для аварии на тупиковой магистрали и ежегодных профилактических работ.

**Не путать:** «ETA конкретной аварии» и «предельно допустимая продолжительность перерыва по нормативу» — разные сущности.
