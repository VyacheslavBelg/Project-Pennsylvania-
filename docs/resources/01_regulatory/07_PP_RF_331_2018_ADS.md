# Постановление Правительства РФ от 27.03.2018 № 331

**Название:** изменения в акты Правительства РФ по вопросам управления МКД и содержания общего имущества.

**Справочная копия:** https://www.consultant.ru/document/cons_doc_LAW_294631/

## Для проекта

Важный источник для организации аварийно-диспетчерского обслуживания, сроков реакции и взаимодействия с жителями. Для каждого конкретного SLA необходимо ссылаться на точный пункт актуальной редакции Правил № 416/№ 354, а не хранить одно универсальное «ответить за N дней».
