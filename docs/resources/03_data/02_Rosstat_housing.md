# Росстат — жилищные условия

Официальная статистика:
https://rosstat.gov.ru/statistics/zhilishhnye_usloviya

ТЗ использует показатель около 4,2 млрд м² общей площади жилищного фонда РФ за 2024 год как оценку масштаба сферы. Этот показатель показывает размер контекста, но не заменяет доказательство конкретной пользовательской боли.
