# Карточка дома, рейтинг и официальный чат

Официальная справка:
https://cdn.dom.gosuslugi.ru/webhelp/topics/mobapp/interface/realty/tab_home/c_interface_realty_tab_home_view-mobapp.html

На главной объекта уже присутствуют:
- новости;
- «важные события», включая плановое отключение горячей воды;
- рейтинг / аналитика УО;
- кнопки «Подать заявку» и «Авария»;
- домовый чат в MAX;
- отчеты по расходованию средств;
- голосования по дому.

**Вывод:** рейтинг УК и «просто новости/объявления» не являются достаточной дифференциацией сами по себе.
