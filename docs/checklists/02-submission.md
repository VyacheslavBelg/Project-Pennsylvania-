- [ ] Версии зафиксированы (`packages.lock.json` / `package-lock.json` / эквивалент)

## 5. Docker-конфигурация

- [ ] `Dockerfile` для каждого локально запускаемого компонента
- [ ] `compose.yaml` или `docker-compose.yml` — запуск **одной командой**
- [ ] `.dockerignore`
- [ ] `.env.example` — **без рабочих токенов, паролей и ключей**
- [ ] Сборка укладывается в **5 минут** (без учёта загрузки базовых образов) — замерено: ____ мин
- [ ] В конфигурации нет избыточных операций, раздувающих сборку

**Прогон с нуля:**

- [ ] `git clone` в пустую папку на машине, где проект никогда не собирался
- [ ] `cp .env.example .env`, заполнены только описанные в README переменные
- [ ] одна команда — всё поднялось
- [ ] сценарий проверки из README пройден по шагам, результат совпал с описанным
- [ ] остановка и повторный запуск по инструкции из README работают

## 7. Только если заявляем собственный API

См. [../tz/06-api-requirements.md](../tz/06-api-requirements.md). **По умолчанию — не заявляем.**

- [ ] HTTPS-адрес, доступный весь период проверки
- [ ] `openapi.yaml` / `openapi.json` (OpenAPI 3.0 или 3.1), синхронный с кодом
- [ ] Тестовые учётные записи для нужных ролей
- [ ] Тестовые данные (JSON/CSV)
- [ ] `DATA-API.yaml` со всеми 9 полями

## Безопасность — отдельный проход

- [ ] `git log -p` / поиск по истории: рабочих токенов, паролей и ключей нет **ни в одном
      коммите**, а не только в текущем состоянии
- [ ] `.env` в `.gitignore`
- [ ] В `.env.example` — только плейсхолдеры
- [ ] Скриншоты в презентации и README не содержат реальных токенов и персональных данных

Секреты нельзя класть в репозиторий (ограничение 8), но нужно указать на служебном слайде
презентации — это единственное место, где они передаются проверяющим.
