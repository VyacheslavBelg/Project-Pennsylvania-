## Приоритеты при нехватке времени

Режем снизу вверх:

| Что | Вклад в балл | Резать |
|---|---|---|
| Сквозной приоритетный сценарий | 18% | никогда |
| Слайд масштабирования | 14% | никогда |
| Архитектура и граница «ядро / переменная часть» | 12% | никогда |
| README, Docker, отсутствие секретов | 18% | никогда — это дисциплина, а не время |
| Обработка ошибок | 6% | нет |
| Модуль 2 | — | во вторую очередь |
| Модуль 3 | — | в первую очередь |
| Платформенный бонус | 0,15 балла | в первую очередь |

0,15 балла бонуса и третий модуль не стоят риска по критерию весом 18%.
