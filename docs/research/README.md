# Research

Эта папка хранит исследовательские артефакты проекта «Домовой».

Правило: исследование не должно незаметно превращаться в продуктовое решение. Для каждого вывода указываем его статус:

- **Факт** — подтвержден первичным/официальным источником или наблюдаемым поведением продукта.
- **Наблюдение** — получено в интервью/тесте; не обобщается на всю аудиторию без дополнительных данных.
- **Гипотеза** — объяснение или предполагаемая ценность, которую ещё нужно проверить.
- **Неизвестно** — неопределённость, способная изменить продукт или архитектуру.

Перед изменением продуктового scope сначала обновляется `docs/project-state/CURRENT.md` и проходит decision gate из актуального baseline.
