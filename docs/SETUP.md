## 1. Корневой сертификат НУЦ Минцифры

**Самый важный пункт.** Без него ни один запрос к API MAX не пройдёт, и ошибка выглядит
непонятно — `SEC_E_UNTRUSTED_ROOT` или «не удалось установить TLS-соединение».

Причина: `platform-api2.max.ru` использует сертификат, выпущенный Минцифры
(`*.max.ru` → `Russian Trusted Sub CA` → `Russian Trusted Root CA`), а этого корня нет
в стандартном хранилище Windows.

Скачать и установить: **https://www.gosuslugi.ru/crt**

Проверить:

```powershell
Get-ChildItem Cert:\CurrentUser\Root, Cert:\LocalMachine\Root |
  Where-Object { $_.Subject -like "*Russian Trusted*" } |
  Select-Object Subject, NotAfter
```

Должен найтись `CN=Russian Trusted Root CA`. Если ничего не выводит — сертификат не установлен
или попал не в то хранилище: нужно «Доверенные корневые центры сертификации».

## 6. Токен бота

Токен выдан организаторами. **В репозиторий он не попадает** — это прямое ограничение ТЗ,
и за секреты в коде снимают баллы.

Берём у Славы, задаём переменной окружения на время сессии:

```powershell
$env:MAX_BOT_TOKEN = "<токен>"
```

```bash
export MAX_BOT_TOKEN='<токен>'
```

Чтобы не вводить каждый раз, можно сохранить в профиль пользователя Windows:

```powershell
[Environment]::SetEnvironmentVariable("MAX_BOT_TOKEN", "<токен>", "User")
```

После этого нужно перезапустить терминал.

## Важно: бота запускает кто-то один

Пока нет сервера, бот работает только на запущенной машине через long polling. Одновременно
опрашивать события может **только один процесс**. Если двое запустят бота с одним токеном,
сообщения начнут доставаться то одному, то другому.

Договаривайтесь в чате, у кого бот поднят.

Сообщения при этом не теряются: пока бот не запущен, события ждут в очереди на стороне
платформы и разбираются при следующем запуске.

## Частые проблемы

| Симптом | Причина | Что делать |
|---|---|---|
| `Не удалось установить TLS-соединение` | нет корневого сертификата Минцифры | пункт 1 |
| `401: токен не принят` | не задан или неверный `MAX_BOT_TOKEN` | пункт 6 |
| Бот молчит, хотя запущен | параллельно работает второй экземпляр и перехватывает события | `Get-Process HelloBot` |
| Правка в коде не работает | сборка упала, потому что запущенный бот блокирует свой `.exe` | остановить процесс, пересобрать |
| Кириллица в консоли — мусор | старый билд без `Console.OutputEncoding` | пересобрать |
| `GET /updates вернул 429` | больше 30 запросов в секунду | не запускать несколько экземпляров |
