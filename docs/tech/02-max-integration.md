### Токен

Токен чат-бота предоставляется организаторами.

- [x] Токен получен, дата: 18.09.2026
- [ ] Токен **не** в репозитории (ограничение 8)
- [ ] Токен записан на служебный слайд презентации (требование формата сдачи)
- [ ] Место хранения для команды: ______________ (не git)

Само значение токена в этот файл и в репозиторий не вносится. Хранится вне git — например,
в переменной окружения на машине разработчика или в закреплённом сообщении команды.

## Компоненты платформы

| Компонент | Что даёт | Используем |
|---|---|---|
| **API чат-ботов** | программная реализация сценариев | да, основа бота |
| **Конструкторы сценариев** | боты без разработки | нет — не даёт дифференциации |
| **MAX Bridge** | взаимодействие мини-приложения с API MAX и API устройства; платформа запуска (iOS, Android, desktop, web) | да |
| **MAX UI** | React-компоненты в стилистике MAX | да |

Мини-приложения работают на HTML/JS/CSS. **Для подключения к MAX мини-приложение должно
работать по HTTPS.**

## Кандидаты на платформенный бонус (+0,15 балла)

> Начисляется **только целиком**. Условие входа: основной пользовательский сценарий полностью
> работает и доступен для проверки. Возможность должна создавать пользовательскую ценность,
> быть **органично встроена** в продукт, работать от начала до результата и быть описана
> в материалах.
>
> Не является основанием: наличие собственного API, дополнительное число функций, базовые
> обязательные возможности.

Заполнить после сверки с документацией в Фазе 0:

| Возможность MAX | Какую ценность даёт пользователю | Трудоёмкость | Берём |
|---|---|---|---|
| | | | ⬜ |
| | | | ⬜ |

Бонус берём только после того, как приоритетный сценарий закрыт полностью: 0,15 балла не стоят
риска провалить критерий весом 18%.

## Проверка в обеих версиях MAX

Ограничение 3: функциональность доступна пользователям **в обеих версиях** платформы.

| Что проверяем | Мобильная | Веб |
|---|---|---|
| Бот отвечает | ⬜ | ⬜ |
| Мини-приложение открывается из бота | ⬜ | ⬜ |
| Основной сценарий проходится целиком | ⬜ | ⬜ |
| Вёрстка не ломается | ⬜ | ⬜ |
| Обработка ошибок работает | ⬜ | ⬜ |

Проверять по ходу разработки в конце каждой фазы, не перед сдачей.
