# HelloBot

Проверка связи с MAX Bot API. Бот обрабатывает несколько команд и отвечает «Hello, World!»
на остальные сообщения.

Это задача 0.6 из [плана](../../docs/ACTION-PLAN.md) — не заготовка продукта. Настоящий бэкенд
поднимается в Фазе 2 по [tech/01-architecture.md](../../docs/tech/01-architecture.md).

## Зачем именно long polling

`GET /updates` не требует публичного адреса, поэтому бот запускается с локальной машины без
хостинга, домена и туннеля. Для прода документация MAX требует вебхук — `POST /subscriptions`.

## Что нужно

| | |
|---|---|
| .NET SDK | 10.x |
| Токен бота | выдан организаторами |
| Корневой сертификат НУЦ Минцифры | **обязательно**, иначе TLS-соединение не установится |

### Сертификат

API MAX отдаёт цепочку `*.max.ru` → `Russian Trusted Sub CA` → `Russian Trusted Root CA`.
Корня Минцифры нет в стандартном хранилище Windows, и без него любой запрос падает с
`SEC_E_UNTRUSTED_ROOT`.

Скачать: https://www.gosuslugi.ru/crt

Проверить, что установлен:

```powershell
Get-ChildItem Cert:\CurrentUser\Root, Cert:\LocalMachine\Root |
  Where-Object { $_.Subject -like "*Russian Trusted*" }
```

## Запуск

Токен передаётся через переменную окружения и в репозиторий не попадает.

```powershell
$env:MAX_BOT_TOKEN = "<токен>"
dotnet run
```

```bash
export MAX_BOT_TOKEN='<токен>'
dotnet run
```

При старте бот вызывает `GET /me` — выводит имя и фактический ник бота, после чего начинает
опрашивать события. Напишите боту в MAX, в консоли появится входящее сообщение и отправленный
ответ.

## Команды

| Команда | Ответ |
|---|---|
| `/start` | подсказка по командам |
| `/besthackatonteam` | `наMAXималках` |
| любое другое сообщение | `Hello, World!` |

Команды обрабатываются в коде, поэтому работают сразу. В меню бота они не появятся: список
команд объявляется в кабинете платформы, доступа к которому у команды нет. В групповых чатах
команда приходит с ником — `/besthackatonteam@t273_hakaton_max_bot` — этот вариант тоже
распознаётся.

## Перед пересборкой остановите бота

Запущенный процесс держит `bin/Debug/net10.0/HelloBot.exe` открытым, и сборка падает с
`MSB3021: файл используется другим процессом`. Если не заметить ошибку, легко запустить старый
бинарник и решить, что правка не работает.

```powershell
Get-Process HelloBot -ErrorAction SilentlyContinue | Stop-Process -Force
dotnet build
```

Отдельно: `Ctrl+C` или таймаут поверх `dotnet run` убивает обёртку, а дочерний `HelloBot.exe`
может остаться жить и продолжить опрашивать события. Перед запуском стоит убедиться, что
лишних экземпляров нет — одновременно опрашивать может только один процесс, иначе они
перехватывают сообщения друг у друга.

## Коды ошибок

| Что видно | Причина |
|---|---|
| `Не удалось установить TLS-соединение` | не установлен корневой сертификат Минцифры |
| `401: токен не принят` | неверное значение `MAX_BOT_TOKEN` |
| `GET /updates вернул 429` | превышен лимит 30 запросов в секунду |
